# Руководство по установке

## Первый запуск

При первом открытии script4video приложение проверит наличие необходимых зависимостей (FFmpeg). Если FFmpeg не установлен, появится диалоговое окно загрузки.

Нажмите **«Загрузить FFmpeg»** и дождитесь завершения загрузки. Обычно это занимает 1-2 минуты в зависимости от вашего интернет-соединения.

## Ручная установка

Если автоматическая загрузка не удалась, можно установить FFmpeg вручную.

### Шаг 1: Загрузка FFmpeg

Скачать FFmpeg для вашей платформы:

| Платформа | Ссылка на скачивание |
|----------|---------------|
| Windows | [ffmpeg-release-essentials.zip] (https ://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip) |
| macOS | [ffmpeg.zip] (https://evermeet.cx/ffmpeg/) |
| Linux | [ffmpeg-release-amd64-static.tar.xz] (https://johnvansickle.com/ffmpeg/releases/ffmpeg-release-amd64-static.tar.xz) |

### Шаг 2: Поиск папки установки

Откройте папку, в которой script4video хранит свои данные:

| Платформа | Путь к папке |
|----------|-------------|
| Windows | 'C :\Users\< ВашеИмя >\.script4video\bin\' |
| macOS | '/Пользователи/< ВашеИмя >/.script4video/bin/' |
| Linux | '/home/< Ваше имя >/.script4video/bin/' |

Если папка `bin` не существует, создайте ее.

### Шаг 3: Извлечение и копирование файлов

Извлеките загруженный архив и скопируйте следующие файлы в папку `bin`:

**Windows:**
```
ffmpeg.exe
ffprobe.exe
```

**macOS/Linux:**
```
ffmpeg
ffprobe
```

### Шаг 4: Перезапустите приложение

Закрыть и снова открыть script4video. Теперь приложение должно обнаружить FFmpeg и работать правильно.

## Поиск и устранение неисправностей

### «FFmpeg не найден» после ручной установки

- Проверьте, что файлы названы точно `ffmpeg.exe` и `ffprobe.exe` (Windows) или `ffmpeg` и `ffprobe` (macOS/Linux)
- Убедитесь, что файлы находятся в папке `bin`, а не в подпапке
- На macOS/Linux: убедитесь, что файлы имеют разрешение на выполнение (`chmod +x ffmpeg ffprobe`)

### Сбой загрузки или зависание

- Проверьте подключение к Интернету
- Попробуйте скачать вручную (см. выше)
- Временно отключить брандмауэр/антивирус и повторить попытку

### «Сбой выполнения FFmpeg»

- Возможно, загруженный файл поврежден. Удалите его и повторите попытку
- На macOS: возможно, вам придется разрешить приложение в системных настройках> Безопасность и конфиденциальность
- В Windows: может потребоваться разблокировать файл (щелкните правой кнопкой мыши> Свойства> Разблокировать)

## Переустановка приложения

При переустановке или обновлении script4video:

- Ваша установка FFmpeg сохранена
- Ваши настройки сохранены
- Нет необходимости загружать FFmpeg снова

## Полное удаление приложения

Чтобы полностью удалить script4video и все его данные:

1. Удалите приложение нормально
2. Удалите папку `.script4video` из домашнего каталога
