# **Минуты**
### **Расчет минут**
Когда пользователь нажимает на кнопку создать видео  
Происходят проверки настроек, затем тех ресурсов, которые подпадают под критерии  
Происходит расчет потенциально максимальнной длины всех создаваемых видеороликов  
Когда потенциальная длинна видеороликов известна, у пользователя резервируются потенциально использованнные минуты, они визуально списываются с баланса в начале генерации видео

По окончании генерации видеороликов (успех, отмена), минуты из резервированных становятся списанными (потраченными), списание происходит только за созданные видео  
**Успех** - все видео были созданы, процесс генерации не отменялся  
**Отмена** - генерация видеороликов была прервана, минуты будут списаны только за созданные аидео  

Видео которое было в обработке в процессе отмены, не будет создано и файл видео будет удален

### **Пример потребления на основе экрана (Аудио истории)**
На экране аудиоисторий расчет минут происходит след. образом
1 минута (токен) - за 1 минуту созданного видео
Расчет длинны видео происходит исходя из длины аудиодорожки
Если адиодорожка составляет 6 минут 45 секунд, минуты будут списаны за 6 минут готового видео 
(происходит округление в пользу пользователя)

Если в директории находятся 12 аудиодорожек, критериям для создания удовлетворяют 6, потенциальный расход токенов будет составлять
сумма длин 6 аудиодорожек. Допустим каждая аудиодорожка 7 минут длиной.
При нажатии на кнопку создать видео, у пользователя будет зарезервированно 42 токена
По окончании создания ВСЕХ видео, зарезервированные минуты будут считаться потраченными
При отмене, будет списано только то число токенов, сколько полных видео было сделано до отмены
0 видео было сделано - 42 токена вернуться на счет пользователя
3 видео было сделано - 21 токен спишется, 21 вернется пользователю и т.д.

### **Обработка ошибок**
Если в процессе создания видеоролика произел сбой интренет сети, и генерация завершилась без сети (отмена, успех)
В таком случае информация о созданных видео сохраняется на устройстве 
При следующем запуске приложение отправит на сервис информацию о проведенной операции и минуты расчитаются согласно созданным видео (списание только за созданные видео, возврат за видео, которые созданы не были)
До тех пор, минуты будут оставаться зарезервированными (до получения статуса операции)
Если статус операции не пришел в течении 2х дней, зарезервированные минуты будут списаны в полном обьеме
Для отправки статуса операции достаточно запустить приложение (при доступной сети интернет) в срок до 2х дней с момента проведения операции

### **Расчет потребления для каждого экрана**
**Аудио-истории**
1 минута (токен) - за 1 минуту созданного видео
Расчет происходит по длине аудиодорожки, на основе которой будет создаваться видео
