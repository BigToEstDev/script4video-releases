# Руководство по первому запуску

В этом руководстве вы узнаете о начальной настройке приложения script4video.

---

## Шаг 1: Подключите свое устройство

При первом запуске приложения вы увидите экран "Подключите свое устройство".

Чтобы использовать приложение, вам необходимо привязать это устройство к своей учетной записи:

1. Нажмите кнопку **"Открыть браузер, чтобы привязать устройство"**
2. Откроется браузер по умолчанию со страницей аутентификации
3. Войдите в свою учетную запись или создайте новую
4. Приложение автоматически определит, когда подключение будет завершено
5. Вы будете перенаправлены на главный экран

**Идентификатор устройства**: На этом экране отображается уникальный идентификатор вашего компьютера. Этот идентификатор используется для идентификации вашего устройства в вашей учетной записи.

> **Совет**: Вы можете отменить процесс привязки в любое время, нажав кнопку "Отмена".

---

## Шаг 2: Проверка среды

При первом запуске приложение автоматически проверяет, установлены ли все необходимые компоненты:

- **FFmpeg** - Требуется для обработки видео

Вы увидите диалоговое окно проверки:

| Статус | Значение |
|--------|---------|
| Проверка... | Приложение проверяет установку FFmpeg |
| Приложение готово! | Все настроено правильно. Нажмите "ОК", чтобы продолжить |
| Ошибка FFmpeg | Возникла проблема с FFmpeg. Нажмите "Попробовать еще раз", чтобы повторить попытку |

> **Примечание**: Эта проверка выполняется только один раз. После успешной проверки вы больше не увидите это диалоговое окно.

---

## Шаг 3: Обзор главного экрана

После успешной настройки вы увидите главный экран с:

### Значками верхней панели (справа)

| Значок | Функция |
|------|----------|
| Значок процессора | Откройте настройки устройства рендеринга |
| Значок шестеренки | Откройте языковые настройки |
| Значок пользователя | Откройте диалоговое окно учетной записи |

### Экраны для создания видео

В основной области отображаются доступные режимы создания видео:
- **Аудиоистории** - Создание видео из аудиофайлов с фоновыми изображениями

Скоро появятся дополнительные режимы, помеченные как "WIP" (Работа продолжается).

---

## Советы по быстрому запуску

1. **Установите свой язык** - Нажмите на значок шестеренки, чтобы выбрать предпочитаемый язык (английский или русский)
2. **Выберите устройство рендеринга** - Нажмите на значок процессора, чтобы выбрать, какой процессор (CPU или GPU) будет рендерить ваши видео. Использование выделенного графического процессора ускоряет создание видео
3. **Проверьте свой баланс** - Нажмите на значок пользователя, чтобы просмотреть доступные минуты и информацию об учетной записи.
4. **Начать создание** - Нажмите на "Аудиоистории", чтобы начать создание вашего первого видео

---

## Нужна помощь?

Если во время настройки возникнут какие-либо проблемы:
- Убедитесь, что у вас есть активное подключение к Интернету
- Попробуйте перезапустить приложение
- Убедитесь, что ваш браузер разрешает всплывающие окна для страницы аутентификации
- Обратитесь в службу поддержки через веб-приложение
