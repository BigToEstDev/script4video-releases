# **Shorts Split**
Экран Shorts Split открывается с главной страницы приложения
Он предназначен для создания видео в формате разделенного экрана в стиле реакций
Экран объединяет основное видео с видео-реакцией в вертикальном формате

Основой для создания видео являются основные видео из папки загрузки
Видео создаются в **вертикальном** формате 9:16, подходящем для YouTube Shorts, TikTok и Instagram Reels

### **Директории**
Для работы с этим экраном есть 4 раздела:
* Директория с видео - основные видео контента, которые будут использоваться как первичный источник видео
* Директория с реакциями - видео-реакции, которые будут объединены с основным видео
* Директория сохранения - все готовые видео будут сохранены в эту директорию, она должна быть уникальной и не совпадать с другими директориями
* Директория для использованных видео - после успешной генерации исходные видео перемещаются сюда, чтобы избежать повторной генерации видео из уже использованного контента

### **Настройка видео**
В панели опций есть вкладка Кастомизация со следующими настройками:

**Позиция контента** - определяет вертикальное расположение видео:
* Видео-Реакция - основное видео отображается сверху, видео-реакция снизу
* Реакция-Видео - видео-реакция отображается сверху, основное видео снизу

**Соотношение разделения** - контролирует распределение пространства экрана между видео:
* 50-50 - оба видео занимают равное пространство
* 60-40 - основное видео занимает 60%, реакция 40%
* 70-30 - основное видео занимает 70%, реакция 30%

Соотношение разделения всегда относится к размеру основного видео независимо от позиции контента.

### **Настройки видео**
Во вкладке Настройки можно настроить поведение обработки видео:

**Максимальная длина видео** - как обрабатывать видео длиннее 3 минут:
* Пропустить видео - видео длиннее 3 минут будут пропущены при генерации
* Обрезать видео - видео длиннее 3 минут будут обрезаны до 3 минут

**Минимальная длина видео** - все видео короче 20 секунд будут игнорироваться при создании видео

**Политика реакций** - как применяются видео-реакции:
* Зациклить реакцию - если видео-реакция короче основного видео, она будет зациклена для соответствия длительности
* Использовать разные реакции - несколько разных клипов реакций будут использоваться последовательно для заполнения длительности

Если видео-реакция длиннее основного видео, она будет обрезана для соответствия длительности основного видео.

### **Превью**
Панель превью показывает, как будет выглядеть финальная компоновка видео на основе выбранной позиции контента и соотношения разделения. Миниатюры из папок с видео и реакциями отображаются в соответствующих позициях.

Нажмите кнопку обновления рядом с превью, чтобы перезагрузить миниатюры, если вы добавили новые видео в папки.

### **Поддерживаемые форматы**
Поддерживаются следующие форматы видео: MP4, MOV, AVI, MKV, WEBM, WMV, FLV, M4V

### **Расчет и потребление токенов**
На экране Shorts Split минуты рассчитываются следующим образом:
2 минуты (токена) за 10 секунд созданного шортса.
Расчет основан на длине видеодорожки (не видео реакций), на основе которой будет создано видео.

Если видеозапись не делится на 10 секунд, она будет округлена до ближайшего целого числа 10-секундных отрезков.
(округление в пользу пользователя)

Когда вы нажимаете кнопку Генерация, токены будут зарезервированы на основе общей ожидаемой длительности.
По окончании ВСЕГО создания видео зарезервированные минуты (токены) будут считаться потраченными.
При отмене будет списано только количество токенов за завершенные видео до отмены.

### **Сохранение настроек**
Все настройки и параметры автоматически сохраняются в папке
.script4video в settings.json в разделе shortsSplit

### **Сохранение видео**
* Видео сохраняются с оригинальным названием видео + временная метка создания
