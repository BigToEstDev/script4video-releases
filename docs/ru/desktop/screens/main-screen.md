# **Главный экран**
### **Информация о пользователе**
На главном экране в верхней панели есть иконка аккаунта, по нажатию открывается диалог
В окне пользователя есть:
* Почта пользователя
* Device Id сокращенный
* Число минут в аккаунте
* Кнопка отвязать устройство - устройство отвяжется от аккаунта

### **Настройки языка**
Приложение поддерживает 2 языка: Русский и Английский
Выбранный язык автоматически сохраняются в папке
.script4video в файле settings.json в разделе главного экрана

### **Рендер**
В приложении есть возможность выбора, на каком чипе будет происходить рендер видео
На главном экране при нажатии на иконку редера будет открыт диалог с опциями
В диалоге представлен CPU и все GPU которые есть на устройстве

При выборе натройки, рендер будет происходить на выбранном чипе
Можно выбрать **1** чип для ренедера за раз

Выбранный чип автоматически сохраняются в папке
.script4video в файле settings.json в разделе главного экрана
Дальнейшир рендер всех видео будет происходить на выбраном чипе

Чип внешней видеокарты GPU (не встроенной в CPU) лучше подходит для создания видео

### **Экраны**
На главном экране приложения представлены все экраны для создания видео
Каждый отвечает за создание видео под определенную нишу или выполнение определенной задачи
В текущий момент в приложении есть:
* Экран для создания [Аудио историй](/desktop/screens/audio-stories)
