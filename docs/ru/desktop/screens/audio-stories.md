# **Аудио истории**
Канал аудио историй открывается с главной страницы приложения
Он предназначен для создания видео формата аудио-истории
На фоне аудиодорожки идет показ картинок и опционально субтитров

Основой для создания видео являются аудиодорожки
Видео создаются в **горизонтальном** формате 16:9

### **Директории**
Для работы с данным экраном есть 4 раздела:
* Директория с аудио - отсюда будут браться все аудио для создания видео
* Директория с изображениями - отсюда будут браться все изображения для создания видео
* Диретория с субтитрами - при создании видео допускается, что видео будет без субтитров. Если директория не выбрана, субтитры не будут добавлены. Субтитры поддерживаются в формате .SRT. Для добавления субтитров к видео файл субтитров должен иметь такое же **название** как и аудио файл, к которому он будет применен. Пример - название аудио audio_1, название файла субтитров должно быть audio_1
*  Директория сохранения - в эту диреторию будут сохраняться все готовые видео, она должна быть уникальной и не совпадать с другими директориями
* Директория для сгенерированных айдио - в эту директорию попадают аудио, видео для которых были сгенерированы. Это сделано для того чтобы избежать повторной генерации видео из уже использованного аудио.

### **Настройки видео**
В верхней панели экрана расположена иконка настроек видео
В настройках видео представлены след. настройки:
* Максимальное число видео - максимальное число видео которое будет создано за 1 вызов создания, вне зависимости от числа аудиодорожек в папке
* Минимальная длина аудиодорожки - все дорожки короче этого числа будут игнорироваться при создании видео
* Максимальная длина аудиодорожки - все дорожки больше этого числа будут игнорироваться при создании видео
* Время показа картинки - сколько времени будет происходить показ картинки на итоговом видео, после этого времени произойдет смена изображения
* Фильтровать не 16:9 изображения - если в директории для изображений находятся изображения формата не только 16:9, то при включенной этой настройке, такие изображения будут фильтроваться, при отключенной настройке для создания видео будут допущены все изображения из директории. В случае если формат картинки 2:3 (пример), картинка будет вписана в формат 16:9 - появятся черные края по бокам видео при показе такой картинки

### **Отображение картинок на preview**
Картинки при создании видео подбираются в случайном порядке, в случае если в директориии только 1 картинка, которая подходит под выбранные парамерты, будет показана только она на протяжении всего видео.

Отображение картинок на превью - картинки подгружаются автоматически. Можно посмотреть какие картинки будут использоваться в видео, для этого по бокам превью есть стрелочки для пролистывания картинок.

### **Отображение субтитров Preview и редактирование субтитров**
В верхней панели экрана расположена иконка настроек внешнего вида субтитров для видео
Представлены след. механизмы кастомизации субтитров:
* Выбор шрифта - доступны 8 шрифтов
* Размер шрифта
* Жирность шрифта
* Использовать только заглавные буквы
* Выбор цвета текста
* Выбор цвета обводки текста
* Толщина обводки текста, если равна 0 - обводки не будет
* Размытие обводки текста

Вся кастомизация субтитров будет отображена на превью.

### **Применение субтитров к видео**
При создании видео допускается, что видео будет без субтитров. Если директория не выбрана, субтитры не будут добавлены. Субтитры поддерживаются в формате .SRT. Для добавления субтитров к видео файл субтитров должен иметь такое же **название** как и аудио файл, к которому он будет применен. Пример - название аудио audio_1, название файла субтитров должно быть audio_1.

Установленные параметры внешнего видео субтитров будут примененеы ко **всем** видео, которые будут созданы в рамках одного цикла

### **Расчет и Потребление токенов**
На экране аудиоисторий расчет минут происходит след. образом
1 минута (токен) - за 1 минуту созданного видео
Расчет длинны видео происходит исходя из длины аудиодорожки
Если адиодорожка составляет 6 минут 45 секунд, минуты (токены) будут списаны за 6 минут готового видео 
(происходит округление в пользу пользователя)

Если в директории находятся 12 аудиодорожек, критериям для создания удовлетворяют 6, потенциальный расход токенов будет составлять - сумма длин 6 аудиодорожек. Допустим каждая аудиодорожка 7 минут длиной.
При нажатии на кнопку создать видео, у пользователя будет зарезервированно 42 токена
По окончании создания ВСЕХ видео, зарезервированные минуты (токены) будут считаться потраченными
При отмене, будет списано только то число токенов, сколько полных видео было сделано до отмены
0 видео было сделано - 42 токена вернуться на счет пользователя
3 видео было сделано - 21 токен спишется, 21 вернется пользователю и т.д.

### **Сохранение настроек**
Все настройки и параметры автоматически сохраняются в папке
.script4video в файле settings.json в разделе аудио историй

### **Сохранение видео**
* Видео сохраняется в формате название аудио + время создания
