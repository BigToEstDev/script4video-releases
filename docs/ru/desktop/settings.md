# Настройки
В этом руководстве описаны все доступные настройки в приложении script4video.

---

## Расположение файла настроек
Все настройки сохраняются автоматически и сохраняются при перезапуске приложения.

| Платформа | Путь |
|----------|------|
| Windows | `C:\Users\<username>\AppData\Roaming\.script4video\settings.json` |
| macOS | `~/Library/Application Support/.script4video/settings.json` |
| Linux | `~/.local/share/.script4video/settings.json` |

---

## Глобальные настройки
Эти настройки применимы ко всему приложению.

### Язык
**Местоположение**: Главный экран > Значок шестеренки > Язык
Выберите язык интерфейса для всего приложения.

| Опция | Описание |
|--------|-------------|
| Английский | Английский интерфейс |
| Русский | Русский интерфейс |

**По умолчанию**: Системный язык (английский, если системный язык не русский)
**Примечание**: Изменения языка немедленно применяются ко всем экранам и диалоговым окнам.

---

### Устройство рендеринга
**Расположение**: Главный экран > Значок процессора
Выберите, какой процессор будет использоваться для рендеринга видео.

| Опция | Описание |
|--------|-------------|
| CPU | Используйте основной процессор (более медленный, но всегда доступный) |
| GPU (название может варьироваться) | Рекомендуется использовать видеокарту (более быструю) |

**По умолчанию**: CPU
**Как выбрать**:
- Если у вас есть выделенная видеокарта (NVIDIA, AMD), выберите ее для ускорения рендеринга
- Если у вас есть только встроенный графический процессор (Intel UHD, AMD Radeon Graphics), скорость процессора может быть сопоставимой
- Вы можете выбрать только одно устройство для рендеринга одновременно
**Совет**: Откройте диспетчер задач во время рендеринга, чтобы проверить, какое устройство используется.

---

## Настройки учетной записи
**Местоположение**: Главный экран > Значок пользователя
Просмотр информации о вашей учетной записи и управление ею.

| Поле | Описание |
|-------|-------------|
| Электронная почта | Адрес электронной почты вашей учетной записи |
| Идентификатор устройства | Уникальный идентификатор этого устройства (отображаются первые 16 символов) |
| Минуты | Доступный баланс токенов |

### Отключите подключение устройства
Это устройство будет удалено из вашей учетной записи. После отключения подключения:
- Вам нужно будет снова подключить устройство, чтобы использовать приложение
- Ваши минуты остаются в вашем аккаунте
- Перед отменой подключения появится диалоговое окно подтверждения

## Настройки аудиосказок
Настройки, относящиеся к режиму создания видео с аудиосказками.

### Настройки видео
**Местоположение**: Экран аудиосказок > Значок шестеренки

#### Максимальное количество видео
Максимальное количество видеороликов, создаваемых в одном пакете.

| Параметр | Значение |
|-----------|-------|
| Диапазон | 1 - 100 |
| По умолчанию | 10 |

**Пример**: Если задано значение 10, а в вашей аудиопапке 20 файлов, будет создано только 10 видеороликов.

---

#### Минимальная продолжительность аудио
Минимальная длина аудиофайла (в минутах), которая должна быть обработана.

| Параметр | Значение |
|-----------|-------|
| Диапазон | от 1 до 60 минут |
| По умолчанию | 1 минута |

Аудиофайлы, длина которых меньше этого значения, будут пропущены.

---

#### Максимальная продолжительность звука
Максимальная длина аудиофайла (в минутах), которая должна быть обработана.

| Параметр | Значение |
|-----------|-------|
| Диапазон | от 5 до 60 минут |
| По умолчанию | 60 минут |

Аудиофайлы, продолжительность которых превышает это значение, будут пропущены.
**Примечание**: Минимальная продолжительность звука должна быть меньше максимальной. При необходимости приложение автоматически скорректирует значения.

---

#### Длительность изображения
Как долго отображается каждое фоновое изображение перед переключением на следующее.

| Параметр | Значение |
|-----------|-------|
| Диапазон | от 1 до 5 минут |
| По умолчанию | 3 минуты |

**Пример**: Если установлено значение 3 минуты, а продолжительность звука составляет 12 минут, в видео будут последовательно показаны 4 разных изображения.

---

#### Пропустить изображения, не относящиеся к 16:9
Если этот параметр включен, изображения, не соответствующие соотношению сторон 16:9, использоваться не будут.

| Значение | Поведение |
|-------|----------|
| Включено | Используются только изображения формата 16:9 |
| Отключено | Используются все изображения (может привести к растягиванию или обрезке) |

**По умолчанию**: Отключено

---

### Настройки субтитров
**Расположение**: Экран аудиосюжетов > Кнопка "S"
Настройте отображение субтитров в ваших видео.

#### Шрифт
Выберите семейство шрифтов для субтитров.

| Доступные шрифты |
|-----------------|
| Arial |
| Times New Roman |
| Verdana |
| Джорджия |
| Courier New |
| Impact |
| Comic Sans MS |
| Требюше MS |

**По умолчанию**: IBM Plex Mono

---

#### Размер шрифта
Размер текста субтитров.

| Параметр | Значение |
|-----------|-------|
| Диапазон | 8 - 32 |
| По умолчанию | 16 |

---

#### Размер шрифта
Толщина/жирность текста субтитров.

| Параметр | Значение |
|-----------|-------|
| Диапазон | 100 - 900 |
| Шаг | 100 |
| По умолчанию | 400 |

| Значение | Смысл |
|-------|---------|
| 100-300 | Легкий |
| 400 | Нормальный |
| 500-600 | Средний |
| 700-900 | Жирный |

---

#### Заглавные буквы
Преобразовать весь текст субтитров в заглавные буквы.

| Значение | Поведение |
|-------|----------|
| Включено | ВЕСЬ ТЕКСТ НАПИСАН ЗАГЛАВНЫМИ БУКВАМИ |
| Отключено | Текст, записанный в файле субтитров |

**По умолчанию**: Включено

---

#### Цвет текста
Цвет текста субтитров.

| Параметр | Значение |
|-----------|-------|
| Формат | ШЕСТНАДЦАТЕРИЧНЫЙ цвет (#RRGGBB) |
| По умолчанию / #ffffff (белый) |

---

#### Цвет рамки
Цвет контура/обводки текста субтитров.

| Параметр | Значение |
|-----------|-------|
| Формат | ШЕСТНАДЦАТЕРИЧНЫЙ цвет (#RRGGBB) |
| По умолчанию / #000000 (черный) |

---

#### Ширина границы
Толщина контура вокруг текста подзаголовка.

| Параметр | Значение |
|-----------|-------|
| Диапазон | 0 - 10 |
| По умолчанию | 1 |

Установите значение 0, чтобы полностью отключить границу.

---

#### Размытие границ
Примените эффект мягкого размытия к границе субтитров.

| Значение | Поведение |
|-------|----------|
| Включено | Граница имеет мягкие, размытые края |
| Отключено | Граница имеет четкие края |

**По умолчанию**: Отключено
**Примечание**: Размытие границ доступно, только если ширина границы больше 0.

---

## Настройки папки
**Расположение**: Экран "Аудиоистории" > Левая боковая панель
Это рабочие папки, выбранные для каждого сеанса. Они сохраняются и восстанавливаются автоматически.

| Папка | Назначение |
|--------|---------|
| Загрузить аудио | Исходную папку с аудиофайлами (MP3, WAV и т.д.) |
| Загрузить изображения | Исходную папку с фоновыми изображениями (JPG, PNG и т.д.) |
| Загрузить субтитры | Исходную папку с файлами субтитров (формат SRT) |
| Папка сохранения | Целевая папка для сгенерированных видео |
| Сгенерированное аудио | Папка для обработанных аудиофайлов после генерации |

**Важно**: Папка сохранения должна отличаться от всех исходных папок.

---

## Сброс настроек
Для сброса всех настроек по умолчанию:

1. Полностью закройте приложение
2. Перейдите в папку настроек (см. Пути выше)
3. Удалите файл `settings.json`
4. Перезапустите приложение

Все настройки будут восстановлены до значений по умолчанию.
