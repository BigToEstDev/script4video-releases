# First Launch Guide
This guide will walk you through the initial setup of script4video application.

---

## Step 1: Link Your Device
When you launch the app for the first time, you'll see the **Link Your Device** screen.
To use the app, you need to link this device to your account:

1. Click the **"Open Browser to Link Device"** button
2. Your default browser will open with the authentication page
3. Sign in to your account or create a new one
4. The app will automatically detect when linking is complete
5. You'll be redirected to the main screen

**Device ID**: A unique identifier for your computer is shown on this screen. This ID is used to identify your device in your account.
**Tip**: You can cancel the linking process at any time by clicking the "Cancel" button.

---

## Step 2: Environment Verification
On first launch, the app automatically verifies that all required components are installed:
**FFmpeg** - Required for video processing
You'll see a verification dialog:

| Status | Meaning |
|--------|---------|
| Verifying... | The app is checking the FFmpeg installation |
| App is ready! | Everything is set up correctly. Click OK to continue |
| FFmpeg Error | There's an issue with FFmpeg. Click "Try Again" to retry |

**Note**: This verification only happens once. After successful verification, you won't see this dialog again.

---

## Step 3: Main Screen Overview
After successful setup, you'll see the main screen with:

### Top Bar Icons (right side)

| Icon | Function |
|------|----------|
| CPU icon | Open Render Device settings |
| Gear icon | Open Language settings |
| User icon | Open Account dialog |

### Video Creation Screens
The main area shows available video creation modes:
**Audio Stories** - Create videos from audio files with background images

---

## Quick Start Tips
1. **Set your language** - Click the gear icon to select your preferred language (English or Russian)
2. **Choose render device** - Click the CPU icon to select which processor (CPU or GPU) will render your videos. Using a dedicated GPU is faster for video creation
3. **Check your balance** - Click the user icon to see your available minutes and account information
4. **Start creating** - Click on "Audio Stories" to begin creating your first video

---

## Need Help?
If you encounter any issues during setup:
- Make sure you have an active internet connection
- Try restarting the application
- Check that your browser allows pop-ups for the authentication page
- Contact support through the web application
