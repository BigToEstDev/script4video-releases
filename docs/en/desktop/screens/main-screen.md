# **Home Screen**
### **User Information**
There is an account icon on the main screen in the upper panel, a dialog opens by clicking
The user window contains:
* User Mail
* Device Id abbreviated
* Number of minutes in account
* Unlink device button - device will unlink from account

### **Language Settings**
The application supports 2 languages: Russian and English
The selected language is automatically saved in the
.script4video in settings.json in Home screen section

### **Render**
The application has the ability to choose on which chip the video rendering will take place
On the main screen, when you click on the reader icon, a dialog with options will open
The dialog presents the CPU and all GPUs that are on the device

When choosing a pattern, the render will take place on the selected chip
You can choose **1** chip for reneder at a time

The selected chip is automatically saved in the
.script4video in settings.json in Home screen section
Further rendering of all videos will take place on the selected chip

GPU external graphics card chip (not built into the CPU) is better suited for video creation

### **Screens**
The main screen of the application contains all the screens for creating videos
Everyone is responsible for creating a video for a specific niche or performing a specific task
